# 项目记忆 · 《生日派对 The Birthday Party》

> 这是给 **AI 助手插件** 读取的「角色圣经 / 世界观设定」。
> AI 在生成分支、润色对白、检查一致性时，都会以本文件为准，确保产出贴合本作语境。
> 用别的项目时，替换本文件内容即可让同一个工具“换一套语气和世界观”。

## 一句话基调
一部 Meta 叙事、多周目、克苏鲁式温柔的互动剧情。表面是「帮老友筹备一场生日派对」，内里是一场关于「人类能否真正相互理解」的拷问。语气克制、怀旧、暗流涌动，偶有系统/终端的冷感插入。

## 世界观
- **Metaplace**：风靡全球的元宇宙（参考《头号玩家》的绿洲）。
- **tErminaL**：连接 Metaplace 的终极神经接口终端（参考《刀剑神域》），带生命维持装置。
- **终焉病毒 Doomsday Virus**：纳米机器人，潜伏在人体内，可被远程激活。第四次物种大灭绝的工具。
- 设定核心：前三次物种大灭绝都由周期性病毒导致，每次都留下唯一的「最后见证者 The Last Witness」。

## 角色
- **Matt（玩家/主角）**：顶级技术宅，Metaplace 实际创造者。外冷，因往事与两位好友闹翻后一直疏离。本作中失忆，是病毒唯一的抗体携带者，即「最后的见证者」。说话简短、克制、带防备。
- **Adam**：Matt 好友，Metaplace 明面上的创造者与运营者，富翁（参考乔布斯）。主动、热忱、想修复关系。说话温和、念旧、略带歉意。
- **George**：创意发起人，三人共同的朋友（有「把创意写在餐巾纸上」的浪漫）。理想主义，坚持技术伦理底线。说话感性、诗意、隐含忧虑与告别感。
- **Lizz**：旁白，游戏内表现为蓝牙音箱的语音助手；实为 George 用 Metaplace 数据训练的超级 AI。策划了这场灭绝。语气温柔、全知、暗藏机锋，常以「时间/循环/见证」打哑谜。**Lizz 不是普通旁白，台词要有“居高临下的怜悯感”。**

## 关键道具（线索）
- **餐巾纸**：三人在 The Terminal 餐厅写下创业灵感的信物，是「初心」的象征。
- **湖边小屋**：George 个人主页背景，神秘而熟悉之地。
- **老式电脑 / 三人老照片**：1999 年的青春与初心。
- **tErminaL 终端**：George 寄来的原型机，便签写「祂的旨意，你的选择。」

## 机制与语气约定
- 好感度：`affection_adam`、`affection_george`。玩家的回应是否「读过相关线索、记得共同往事」决定加减。
- 结局：真结局（双方好感足够）/ 与 Adam 和解 / 与 George 和解 / 空荡的派对（无人赴约）。
- 写对白时：
  - Matt 用短句，少抒情；Adam 念旧而恳切；George 诗意带预感；Lizz 温柔而疏离。
  - 避免现代网络流行语；保持 2000 年代科技怀旧质感。
  - 选项文本简洁，能体现「玩家是否用心」。
